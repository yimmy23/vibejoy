# 设备与运行约束

- Joy-Con 摇杆先采样校准，测试可预置校准值；其他手柄沿用各自设备适配层，不把 Joy-Con 工厂偏移硬套其他设备。
- HID 句柄可能独占；已有 daemon 时 rumble 等请求经 IPC，不另开同设备。
- Shell 动作异步派发，不能阻塞输入循环。配置错误应包含具体字段路径，未知键/动作不能被静默忽略。
- 动作解析保留现有预编译边界，映射状态便于整体释放/重置；扩展动作同时核对解析、验证、按下/释放与组合动作路径。
- 沿用项目现有类型和模块边界；有真实重复用例才引入新的抽象，避免无关重构。
- 设备协议、依赖补丁与音色精度以当前实现和硬件探针核对，不继承旧版本推测。
